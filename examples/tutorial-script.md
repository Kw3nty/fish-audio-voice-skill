# Озвучка видео через Fish Audio API

## 01 / ХУК

Скидываешь агенту один репозиторий. Он спрашивает только API-ключ и ID голоса. И сам озвучивает видео. Дальше — где взять эти два значения и как работает скилл.

## 02 / КЛЮЧ

Первый вопрос — API-ключ. Заходишь на фиш точка аудио, открываешь API-киз, создаёшь новый ключ и копируешь. Храни его в переменной фиш апи кей. В репозиторий и в код ключ не вставляем.

## 03 / ГОЛОС

Второй вопрос — ID голоса. Открываешь голос в библиотеке. ID — последняя часть адреса или кнопка копирования. Этот ID передаётся в референс айди. Всё, других вопросов скилл не задаёт.

## 04 / СКИЛЛ

Как это работает. В репозитории лежит файл скилл эм ди — инструкция для агента. Он читает её, берёт твой сценарий, режет на главы и запускает скрипт. Модель, формат, паузы и громкость уже настроены.

## 05 / ЗАПРОС

Под капотом — пост на апи точка фиш точка аудио, слэш ви один, слэш ти ти эс. В заголовках ключ и модель эс два точка один про фри. В теле текст, референс айди и формат эм пи три. Одна глава — один запрос: легче перегенерировать только неудачный кусок.

## 06 / СБОРКА

Потом эф эф эм пэг убирает лишнюю тишину, добавляет паузы и нормализует громкость. На выходе вав, тайминг джейсон для сцен, вордс джейсон для субтитров и зип-архив. Остаётся подставить звук в монтаж.

## 07 / РЕПО

Репозиторий лежит на гитхаб. Скачай зип, скинь папку агенту и дай два значения: ключ и ID голоса. Дальше он всё сделает сам. Сохрани видео, чтобы не собирать заново.
